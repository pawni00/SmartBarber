# 💈 SmartBarber – Online Barber Shop Appointment System

## 📌 About the Project

SmartBarber is a simple web-based Online Barber Shop Appointment System.
It allows customers to view barber shop services and book an appointment
online without waiting for a long time at the shop.

## 🎯 Objectives

- Reduce customer waiting time
- Provide easy online appointment booking
- Display available services and prices
- Provide basic information about the barber shop
- Make appointment management simple and convenient

## ✨ Features

- 🏠 Home Page
- ✂️ Services Page
- 📅 Online Appointment Page
- 👤 Customer Name and Phone Number
- 🕐 Date and Time Selection
- 💰 Service and Price Details
- ✅ Appointment Confirmation

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
